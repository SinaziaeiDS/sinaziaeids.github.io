Privacy Policy

Last updated: November 2, 2026

Personal Mail Reader is a private tool used only by its owner to read their own Gmail accounts.

What it accesses

It requests read-only access to Gmail (the gmail.readonly scope). It cannot send, delete, or change email.

How data is used

Email is fetched only when the owner asks for it, and it is shown only to the owner on their own computer. Sign-in tokens are stored in the computer's secure keychain.

Sharing

No data is sold, shared with third parties, used for advertising, or sent to any server run by this tool. The tool has no servers.

Google API data

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
